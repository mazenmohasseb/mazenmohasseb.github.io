How I build secure sites

Security is part of the build, not a plugin added at the end. This page follows the same rules.

  • HTTPS everywhere. No mixed content, and insecure requests are upgraded automatically.

  • A strict Content Security Policy. The browser only runs scripts that come from the site itself.

  • No unnecessary third-party scripts. This page loads nothing from other servers: no analytics, no CDNs, no external fonts.

  • Input validation. Forms check data on the server, not only in the browser.

  • OWASP Top 10 awareness. I check for the most common web vulnerabilities while I build, not after launch.
